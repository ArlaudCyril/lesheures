Case study · SaaS architecture

Orion

A multi-tenant SaaS CRM that powers email and in-app campaigns for LetMeBet. Client applications integrate with Orion through a TypeScript SDK.

My role

I worked on data modelling, API contracts, the admin interface, and client application integration. My SDK work covered the operations available to integrators and the errors they can handle.

Tenant context

In Orion, each campaign belongs to a customer organisation, or tenant. I made the tenant an explicit part of the server context. The API identifies the organisation from the authenticated context and passes it through to business operations and data access.

What changed

Two organisations can make the same call and each receive their own campaigns. When adding a search filter, I can trace the tenant from the API call to the query and check that the filter applies within the organisation’s scope. Storage changes stay on the server as long as the SDK contract stays the same.
