Case study · Mobile

Yoor

A React Native mobile banking app for managing a PCS prepaid card and reviewing transactions on a phone.

My role

I worked on the React Native and Expo app and its integration with PCS banking services. For transaction history, I revised how the app fetches transactions and interprets the API responses.

Reviewing transactions

The banking API can return different fields and labels depending on the transaction. I centralized the conversion in the app’s transaction service so the interface uses the same fields to display a card payment or a top-up.

What I verified

Automated tests check that an approved card payment maps to a completed debit, a waiting top-up maps to a pending credit, and the history request sends the expected wallet and date range.

These tests simulate the API responses. End-to-end testing on a phone remained pending after the fixes.
